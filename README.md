# Combo Time 🧩

**Combo Time** is an action puzzle game where you chain combos by clearing 4 lines at once (Tetris) to achieve the highest score!

## 🎮 Game Overview

Clear falling blocks (Tetriminos) by placing them to fill horizontal lines.

Chain powerful combos by clearing 4 lines simultaneously and aim for the top score before time runs out!

## ✨ Features

* **Simple & Fast-Paced**: Intuitive controls designed for smooth, responsive gameplay.
* **Combo System**: Score multiplier increases as you continuously clear lines.
* **Responsive Design**: Play seamlessly on PC using a keyboard or on mobile devices with touch controls.

## 🕹️ Controls

### Keyboard Controls (PC)

| Key | Action |
| --- | --- |
| **← / →** | Move Left / Right |
| **↓** | Soft Drop |
| **↑** or **Z / X** | Rotate |
| **Space** | Hard Drop |
| **C** or **Shift** | Hold Piece |
| **P** | Pause Game |

## 🚀 How to Play

1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/combo-time.git
   ```

2. Open `index.html` in your browser to start playing immediately! (No web server setup required)
